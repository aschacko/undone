- Saved the trained model as cancellation_logistic.joblib (44.9 KB).
- Selected Logistic Regression over Qwen3-0.6B and MiniLM for now because it requires less storage and should be easier to deploy.
- Prepared the initial AI implementation plan for Requirement 3.
